About

HwguiTurbo — version 1.2.0

WebView2 (Chromium) integration with Hwgui/Harbour.

Stack:
• Clang 22 (MSYS2 CLANG64)
• Harbour (Git)
• Hwgui (dev)
• Microsoft WebView2 Runtime

Architecture: single bind (ExecutarAcao) with command dispatch; JS callbacks callable from Harbour via eval_webview.

Features:

  • WebView2 embedded in the Hwgui window
  • Bidirectional JS ↔ Harbour communication over JSON
  • Single bind with command dispatch
  • JS callbacks callable from Harbour
  • Automatic resize
  • Draggable tabs
  • Soft-delete with DEL badge and Restore
  • Pagination in List and Search
  • Pure Clang build
