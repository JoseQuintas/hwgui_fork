2. Requirements

2.1 Install MSYS2

MSYS2 is the environment that provides Clang 22, the LLD linker, and the required libraries on Windows without depending on Visual Studio.

Download: https://www.msys2.org/

Installation:

  1. Download the installer msys2-x86_64-*.exe
  2. Run it and install to the default path: C:\msys64
  3. On the final screen, check "Run MSYS2 now" and finish
  4. After installation, you will have several shortcuts in the Start menu:
    • MSYS2 UCRT64 — do not use
    • MSYS2 MINGW64 — do not use
    • MSYS2 CLANG64 — use this one
    • MSYS2 MSYS — do not use
Important: every command in this manual must be run inside MSYS2 CLANG64, not in CMD, not in PowerShell, not in the default MSYS2.

2.2 Update MSYS2 (first time)

The first time you open MSYS2 CLANG64, update the package database:

pacman -Syu

If it asks you to close the terminal and reopen, do so and run it again:

pacman -Syu

Repeat until it stops asking to restart.

2.3 Confirm you are in the CLANG64 environment

Before installing anything, confirm you are in the correct environment:

echo $MINGW_PACKAGE_PREFIX

It must print exactly:

mingw-w64-clang-x86_64

If it prints anything else (mingw-w64-ucrt-x86_64, mingw-w64-x86_64, or nothing), you opened the wrong terminal. Close it and open MSYS2 CLANG64.

2.4 Install the required packages

Install the full toolchain, the WebView2 SDK, and Git:

pacman -S --needed \
  mingw-w64-clang-x86_64-toolchain \
  mingw-w64-clang-x86_64-webview2-loader \
  git

During installation, pacman will ask for confirmation several times. Press Enter to accept the default (which is "yes").

What each package provides:

PackageProvides
mingw-w64-clang-x86_64-toolchainClang 22, Clang++, LLD, libc++, libunwind, Windows headers, make, etc.
mingw-w64-clang-x86_64-webview2-loaderWebView2.h, WebView2EnvironmentOptions.h and WebView2Loader.dll
gitGit client (to clone the webview repository)

2.5 Verify the installation

Confirm everything is in place:

clang --version

It should show something like:

clang version 22.1.8 (...)
Target: x86_64-w64-windows-gnu
InstalledDir: C:/msys64/clang64/bin
clang++ --version

It should show the same Clang version, with target x86_64-w64-windows-gnu.

ls /clang64/include/WebView2.h

It should print the file path (no error).

ls /clang64/bin/WebView2Loader.dll

It should print the file path (no error).

git --version

It should print the installed Git version.

If all of these commands returned without errors, the environment is ready. You can move on to section 3.

2.6 Install the WebView2 Runtime (on Windows, outside MSYS2)

The WebView2 Runtime is Microsoft's Chromium engine (around 200 MB) that your application will use at runtime. It is installed on Windows, once, and is not something that ships with your project.

Install via winget (fastest, in CMD):

winget install --id=Microsoft.EdgeWebView2Runtime -e

Manual installation (alternative):

  1. Open: https://developer.microsoft.com/microsoft-edge/webview2/
  2. Look for "Evergreen Standalone Installer"
  3. Download the x64 version
  4. Run the installer as administrator

Confirm it is installed (in CMD):

reg query "HKLM\SOFTWARE\WOW6432Node\Microsoft\EdgeUpdate\Clients\{F3017226-FE2A-4295-8BDF-00C3A9A7E4C5}" /v pv

If it prints something like pv REG_SZ 1xx.x.xxxx.xx, it is installed. If it returns "unable to find the specified registry key or value", it is not installed.

Note: on machines with an up-to-date Windows 10/11, the WebView2 Runtime is usually pre-installed alongside Microsoft Edge. Always confirm with the command above before assuming.

4. Create the C wrapper

Create the file C:\dev\webview\webview_wrapper.c with the following content:

#include <webview/webview.h>
#include <stdint.h>
#include <windows.h>

static webview_t g_webview = NULL;
static WNDPROC   g_old_proc = NULL;
static HWND      g_parent   = NULL;

static LRESULT CALLBACK SubclassProc(HWND hwnd, UINT msg, WPARAM wp, LPARAM lp) {
    if (msg == WM_SIZE && g_webview != NULL) {
        int w = LOWORD(lp);
        int h = HIWORD(lp);
        if (w > 0 && h > 0) {
            webview_set_size(g_webview, w, h, WEBVIEW_HINT_NONE);
        }
    }
    return CallWindowProc(g_old_proc, hwnd, msg, wp, lp);
}

extern "C" {

__declspec(dllexport) void* create_webview_embedded(const char* parent_title, const char* title, int width, int height) {
    HWND hwnd_parent = NULL;
    if (parent_title && parent_title[0]) hwnd_parent = FindWindowA(NULL, parent_title);
    if (!hwnd_parent) hwnd_parent = GetActiveWindow();
    if (!hwnd_parent) hwnd_parent = GetForegroundWindow();
    if (!hwnd_parent) return NULL;

    webview_t w = webview_create(0, NULL);
    if (!w) return NULL;

    webview_set_title(w, title);

    HWND hwnd_wv = (HWND)webview_get_window(w);
    if (!hwnd_wv) { webview_destroy(w); return NULL; }

    LONG_PTR style = GetWindowLongPtr(hwnd_wv, GWL_STYLE);
    style &= ~(WS_POPUP | WS_CAPTION | WS_THICKFRAME | WS_OVERLAPPED |
               WS_SYSMENU | WS_MINIMIZEBOX | WS_MAXIMIZEBOX);
    style |= WS_CHILD;
    SetWindowLongPtr(hwnd_wv, GWL_STYLE, style);

    LONG_PTR exstyle = GetWindowLongPtr(hwnd_wv, GWL_EXSTYLE);
    exstyle &= ~(WS_EX_CLIENTEDGE | WS_EX_WINDOWEDGE |
                 WS_EX_DLGMODALFRAME | WS_EX_STATICEDGE);
    SetWindowLongPtr(hwnd_wv, GWL_EXSTYLE, exstyle);

    SetParent(hwnd_wv, hwnd_parent);

    RECT rc;
    GetClientRect(hwnd_parent, &rc);
    int cw = rc.right > 0 ? rc.right : width;
    int ch = rc.bottom > 0 ? rc.bottom : height;

    webview_set_size(w, cw, ch, WEBVIEW_HINT_NONE);
    SetWindowPos(hwnd_wv, HWND_TOP, 0, 0, cw, ch,
                 SWP_FRAMECHANGED | SWP_NOACTIVATE | SWP_SHOWWINDOW);

    g_webview = w;
    g_parent  = hwnd_parent;
    g_old_proc = (WNDPROC)SetWindowLongPtr(hwnd_parent, GWLP_WNDPROC, (LONG_PTR)SubclassProc);

    return (void*)w;
}

__declspec(dllexport) void navigate_webview(void* w, const char* url) {
    if (!w) return;
    webview_navigate((webview_t)w, url);
}

__declspec(dllexport) void destroy_webview(void* w) {
    if (!w) return;
    if (g_parent && g_old_proc) {
        SetWindowLongPtr(g_parent, GWLP_WNDPROC, (LONG_PTR)g_old_proc);
        g_old_proc = NULL;
        g_parent   = NULL;
    }
    g_webview = NULL;
    webview_destroy((webview_t)w);
}

}

5. Compile the DLL

In MSYS2 CLANG64:

cd /c/dev/webview

clang++ -shared -O2 -std=c++17 -static -x c++ \
  -o webview_wrapper.dll \
  webview_wrapper.c core/src/webview.cc \
  -Icore/include -DUNICODE -D_UNICODE \
  -luser32 -lole32 -loleaut32 -lshlwapi \
  -ladvapi32 -lversion -lcomctl32 -lntdll -ldwmapi \
  -fuse-ld=lld

Flags explained:

FlagMeaning
-sharedBuild a DLL
-O2Optimization
-std=c++17C++ standard used by the webview lib
-staticStatically link libc++/libunwind (avoids depending on MSYS2 DLLs at runtime)
-x c++Treat all files as C++
-Icore/includeDirectory of the webview headers
-DUNICODE -D_UNICODEWin32 macros
-l...Windows libraries
-fuse-ld=lldUse the LLVM linker

Check the exports:

objdump -p webview_wrapper.dll | grep -iE "create_webview|navigate_webview|destroy_webview"

It should print:

create_webview_embedded
destroy_webview
navigate_webview

Check that it does not depend on MSYS2 DLLs (it must not list libc++.dll):

objdump -p webview_wrapper.dll | grep "DLL Name"

It should list only Windows DLLs (KERNEL32.dll, USER32.dll, etc).

7. Harbour (Hwgui) code

File webview_test.prg:

#include "hwgui.ch"
#include "hbdyn.ch"

STATIC pLib     := NIL
STATIC hWebView := NIL

FUNCTION Main()
   LOCAL oForm

   pLib := hb_LibLoad( "webview_wrapper.dll" )
   IF pLib == NIL
      hwg_MsgStop( "hb_LibLoad failed" )
      RETURN NIL
   ENDIF

   INIT WINDOW oForm TITLE "Hwgui + WebView2" SIZE 800, 600 ;
      ON INIT { || InicializaWebView( oForm ) } ;
      ON EXIT { || FinalizaWebView() }

   ACTIVATE WINDOW oForm

   hb_LibFree( pLib )
RETURN NIL

STATIC FUNCTION InicializaWebView( oForm )
   hWebView := hb_DynCall( { "create_webview_embedded", pLib, ;
                             hb_bitOr( HB_DYN_CTYPE_VOID_PTR, HB_DYN_CALLCONV_CDECL ), ;
                             HB_DYN_CTYPE_CHAR_PTR, ;
                             HB_DYN_CTYPE_CHAR_PTR, ;
                             HB_DYN_CTYPE_INT, ;
                             HB_DYN_CTYPE_INT }, ;
                           "Hwgui + WebView2", "WebView2", 760, 540 )
   IF hWebView != NIL
      hb_DynCall( { "navigate_webview", pLib, ;
                    hb_bitOr( HB_DYN_CTYPE_VOID, HB_DYN_CALLCONV_CDECL ), ;
                    HB_DYN_CTYPE_VOID_PTR, ;
                    HB_DYN_CTYPE_CHAR_PTR }, ;
                  hWebView, "https://www.google.com" )
   ENDIF
RETURN NIL

STATIC FUNCTION FinalizaWebView()
   IF hWebView != NIL
      hb_DynCall( { "destroy_webview", pLib, ;
                    hb_bitOr( HB_DYN_CTYPE_VOID, HB_DYN_CALLCONV_CDECL ), ;
                    HB_DYN_CTYPE_VOID_PTR }, ;
                  hWebView )
      hWebView := NIL
   ENDIF
RETURN NIL

Compile:

hbmk2 webview_test.prg \dev\hwgui\hwgui.hbc -lgdiplus

Run:

webview_test.exe

9. How the integration works

  1. Harbour loads webview_wrapper.dll with hb_LibLoad
  2. Harbour calls create_webview_embedded passing the Hwgui window title
  3. The wrapper DLL:
    • Finds the Hwgui window HWND via FindWindowA
    • Creates the WebView2 as a standalone window
    • Removes top-level window styles, turns it into WS_CHILD
    • Calls SetParent to attach it inside the Hwgui window
    • Installs a subclass on the Hwgui window's WM_SIZE
  4. When the user resizes/maximizes, the subclass catches WM_SIZE and calls webview_set_size, resizing the internal Chromium
  5. Harbour calls navigate_webview to load the URL
  6. On close, Harbour calls destroy_webview, which removes the subclass and destroys the WebView

ErrorCauseSolution

webview_create returns NULLWebView2 Runtime not installedInstall the Evergreen Runtime (step 2.6)

WebView stays whiteRendering errorCheck if the WebView2 Runtime is up to date
WebView does not resizeSubclass is not being calledCheck that create_webview_embedded ran without errors
