2. Requisitos

2.1 Instalar MSYS2

MSYS2 es el entorno que proporciona Clang 22, el enlazador LLD y las bibliotecas necesarias en Windows sin depender de Visual Studio.

Descarga: https://www.msys2.org/

Instalación:

  1. Descarga el instalador msys2-x86_64-*.exe
  2. Ejecútalo e instálalo en la ruta predeterminada: C:\msys64
  3. En la pantalla final, marca la opción "Run MSYS2 now" y finaliza
  4. Después de la instalación, tendrás varios accesos directos en el menú Inicio:
    • MSYS2 UCRT64 — no usar
    • MSYS2 MINGW64 — no usar
    • MSYS2 CLANG64 — usar este
    • MSYS2 MSYS — no usar
Importante: todos los comandos de este manual deben ejecutarse dentro de MSYS2 CLANG64, no en CMD, no en PowerShell, no en el MSYS2 estándar.

2.2 Actualizar MSYS2 (primera vez)

La primera vez que abras MSYS2 CLANG64, actualiza la base de paquetes:

pacman -Syu

Si te pide cerrar la terminal y volver a abrirla, hazlo y ejecútalo de nuevo:

pacman -Syu

Repite hasta que deje de pedir reinicio.

2.3 Confirmar que estás en el entorno CLANG64

Antes de instalar cualquier cosa, confirma que estás en el entorno correcto:

echo $MINGW_PACKAGE_PREFIX

Debe mostrar exactamente:

mingw-w64-clang-x86_64

Si muestra cualquier otra cosa (mingw-w64-ucrt-x86_64, mingw-w64-x86_64, o vacío), abriste la terminal equivocada. Ciérrala y abre MSYS2 CLANG64.

2.4 Instalar los paquetes necesarios

Instala el toolchain completo, el SDK de WebView2 y Git:

pacman -S --needed \
  mingw-w64-clang-x86_64-toolchain \
  mingw-w64-clang-x86_64-webview2-loader \
  git

Durante la instalación, pacman pedirá confirmación varias veces. Pulsa Enter para aceptar el valor predeterminado (que es "sí").

Qué proporciona cada paquete:

PaqueteProporciona
mingw-w64-clang-x86_64-toolchainClang 22, Clang++, LLD, libc++, libunwind, cabeceras de Windows, make, etc.
mingw-w64-clang-x86_64-webview2-loaderWebView2.h, WebView2EnvironmentOptions.h y WebView2Loader.dll
gitCliente Git (para clonar el repositorio de webview)

2.5 Verificar la instalación

Confirma que todo está en su sitio:

clang --version

Debe mostrar algo como:

clang version 22.1.8 (...)
Target: x86_64-w64-windows-gnu
InstalledDir: C:/msys64/clang64/bin
clang++ --version

Debe mostrar la misma versión de Clang, con target x86_64-w64-windows-gnu.

ls /clang64/include/WebView2.h

Debe mostrar la ruta del archivo (sin error).

ls /clang64/bin/WebView2Loader.dll

Debe mostrar la ruta del archivo (sin error).

git --version

Debe mostrar la versión de Git instalada.

Si todos estos comandos se ejecutaron sin error, el entorno está listo. Puedes pasar a la sección 3.

2.6 Instalar el WebView2 Runtime (en Windows, fuera de MSYS2)

El WebView2 Runtime es el motor Chromium de Microsoft (unos 200 MB) que tu aplicación usará en tiempo de ejecución. Se instala en Windows, una sola vez, y no forma parte de tu proyecto.

Instalación mediante winget (más rápido, en CMD):

winget install --id=Microsoft.EdgeWebView2Runtime -e

Instalación manual (alternativa):

  1. Abre: https://developer.microsoft.com/microsoft-edge/webview2/
  2. Busca "Evergreen Standalone Installer"
  3. Descarga la versión x64
  4. Ejecuta el instalador como administrador

Confirmar que está instalado (en CMD):

reg query "HKLM\SOFTWARE\WOW6432Node\Microsoft\EdgeUpdate\Clients\{F3017226-FE2A-4295-8BDF-00C3A9A7E4C5}" /v pv

Si muestra algo como pv REG_SZ 1xx.x.xxxx.xx, está instalado. Si devuelve un error de "no se pudo encontrar la clave o el valor del Registro especificado", no está instalado.

Nota: en máquinas con Windows 10/11 actualizado, el WebView2 Runtime normalmente ya viene preinstalado junto con Microsoft Edge. Confirma siempre con el comando anterior antes de asumirlo.

4. Crear el wrapper en C

Crea el archivo C:\dev\webview\webview_wrapper.c con el siguiente contenido:

#include <webview/webview.h>
#include <stdint.h>
#include <windows.h>

static webview_t g_webview = NULL;
static WNDPROC   g_old_proc = NULL;
static HWND      g_parent   = NULL;

static LRESULT CALLBACK SubclassProc(HWND hwnd, UINT msg, WPARAM wp, LPARAM lp) {
    if (msg == WM_SIZE && g_webview != NULL) {
        int w = LOWORD(lp);
        int h = HIWORD(lp);
        if (w > 0 && h > 0) {
            webview_set_size(g_webview, w, h, WEBVIEW_HINT_NONE);
        }
    }
    return CallWindowProc(g_old_proc, hwnd, msg, wp, lp);
}

extern "C" {

__declspec(dllexport) void* create_webview_embedded(const char* parent_title, const char* title, int width, int height) {
    HWND hwnd_parent = NULL;
    if (parent_title && parent_title[0]) hwnd_parent = FindWindowA(NULL, parent_title);
    if (!hwnd_parent) hwnd_parent = GetActiveWindow();
    if (!hwnd_parent) hwnd_parent = GetForegroundWindow();
    if (!hwnd_parent) return NULL;

    webview_t w = webview_create(0, NULL);
    if (!w) return NULL;

    webview_set_title(w, title);

    HWND hwnd_wv = (HWND)webview_get_window(w);
    if (!hwnd_wv) { webview_destroy(w); return NULL; }

    LONG_PTR style = GetWindowLongPtr(hwnd_wv, GWL_STYLE);
    style &= ~(WS_POPUP | WS_CAPTION | WS_THICKFRAME | WS_OVERLAPPED |
               WS_SYSMENU | WS_MINIMIZEBOX | WS_MAXIMIZEBOX);
    style |= WS_CHILD;
    SetWindowLongPtr(hwnd_wv, GWL_STYLE, style);

    LONG_PTR exstyle = GetWindowLongPtr(hwnd_wv, GWL_EXSTYLE);
    exstyle &= ~(WS_EX_CLIENTEDGE | WS_EX_WINDOWEDGE |
                 WS_EX_DLGMODALFRAME | WS_EX_STATICEDGE);
    SetWindowLongPtr(hwnd_wv, GWL_EXSTYLE, exstyle);

    SetParent(hwnd_wv, hwnd_parent);

    RECT rc;
    GetClientRect(hwnd_parent, &rc);
    int cw = rc.right > 0 ? rc.right : width;
    int ch = rc.bottom > 0 ? rc.bottom : height;

    webview_set_size(w, cw, ch, WEBVIEW_HINT_NONE);
    SetWindowPos(hwnd_wv, HWND_TOP, 0, 0, cw, ch,
                 SWP_FRAMECHANGED | SWP_NOACTIVATE | SWP_SHOWWINDOW);

    g_webview = w;
    g_parent  = hwnd_parent;
    g_old_proc = (WNDPROC)SetWindowLongPtr(hwnd_parent, GWLP_WNDPROC, (LONG_PTR)SubclassProc);

    return (void*)w;
}

__declspec(dllexport) void navigate_webview(void* w, const char* url) {
    if (!w) return;
    webview_navigate((webview_t)w, url);
}

__declspec(dllexport) void destroy_webview(void* w) {
    if (!w) return;
    if (g_parent && g_old_proc) {
        SetWindowLongPtr(g_parent, GWLP_WNDPROC, (LONG_PTR)g_old_proc);
        g_old_proc = NULL;
        g_parent   = NULL;
    }
    g_webview = NULL;
    webview_destroy((webview_t)w);
}

}

5. Compilar la DLL

En MSYS2 CLANG64:

cd /c/dev/webview

clang++ -shared -O2 -std=c++17 -static -x c++ \
  -o webview_wrapper.dll \
  webview_wrapper.c core/src/webview.cc \
  -Icore/include -DUNICODE -D_UNICODE \
  -luser32 -lole32 -loleaut32 -lshlwapi \
  -ladvapi32 -lversion -lcomctl32 -lntdll -ldwmapi \
  -fuse-ld=lld

Explicación de las banderas:

BanderaSignificado
-sharedGenerar DLL
-O2Optimización
-std=c++17Estándar C++ usado por la lib webview
-staticEnlaza estáticamente libc++/libunwind (evita depender de las DLL de MSYS2 en tiempo de ejecución)
-x c++Trata todos los archivos como C++
-Icore/includeDirectorio de las cabeceras de webview
-DUNICODE -D_UNICODEMacros de Win32
-l...Bibliotecas de Windows
-fuse-ld=lldUsar el enlazador de LLVM

Verifica los exports:

objdump -p webview_wrapper.dll | grep -iE "create_webview|navigate_webview|destroy_webview"

Debe mostrar:

create_webview_embedded
destroy_webview
navigate_webview

Verifica que no depende de DLL de MSYS2 (no debe listar libc++.dll):

objdump -p webview_wrapper.dll | grep "DLL Name"

Debe listar solo DLL de Windows (KERNEL32.dll, USER32.dll, etc.).

7. Código Harbour (Hwgui)

Archivo webview_test.prg:

#include "hwgui.ch"
#include "hbdyn.ch"

STATIC pLib     := NIL
STATIC hWebView := NIL

FUNCTION Main()
   LOCAL oForm

   pLib := hb_LibLoad( "webview_wrapper.dll" )
   IF pLib == NIL
      hwg_MsgStop( "hb_LibLoad falló" )
      RETURN NIL
   ENDIF

   INIT WINDOW oForm TITLE "Hwgui + WebView2" SIZE 800, 600 ;
      ON INIT { || InicializaWebView( oForm ) } ;
      ON EXIT { || FinalizaWebView() }

   ACTIVATE WINDOW oForm

   hb_LibFree( pLib )
RETURN NIL

STATIC FUNCTION InicializaWebView( oForm )
   hWebView := hb_DynCall( { "create_webview_embedded", pLib, ;
                             hb_bitOr( HB_DYN_CTYPE_VOID_PTR, HB_DYN_CALLCONV_CDECL ), ;
                             HB_DYN_CTYPE_CHAR_PTR, ;
                             HB_DYN_CTYPE_CHAR_PTR, ;
                             HB_DYN_CTYPE_INT, ;
                             HB_DYN_CTYPE_INT }, ;
                           "Hwgui + WebView2", "WebView2", 760, 540 )
   IF hWebView != NIL
      hb_DynCall( { "navigate_webview", pLib, ;
                    hb_bitOr( HB_DYN_CTYPE_VOID, HB_DYN_CALLCONV_CDECL ), ;
                    HB_DYN_CTYPE_VOID_PTR, ;
                    HB_DYN_CTYPE_CHAR_PTR }, ;
                  hWebView, "https://www.google.com" )
   ENDIF
RETURN NIL

STATIC FUNCTION FinalizaWebView()
   IF hWebView != NIL
      hb_DynCall( { "destroy_webview", pLib, ;
                    hb_bitOr( HB_DYN_CTYPE_VOID, HB_DYN_CALLCONV_CDECL ), ;
                    HB_DYN_CTYPE_VOID_PTR }, ;
                  hWebView )
      hWebView := NIL
   ENDIF
RETURN NIL

Compilar:

hbmk2 webview_test.prg \dev\hwgui\hwgui.hbc -lgdiplus

Ejecutar:

webview_test.exe

9. Cómo funciona la integración

  1. Harbour carga webview_wrapper.dll con hb_LibLoad
  2. Harbour llama a create_webview_embedded pasando el título de la ventana Hwgui
  3. La DLL wrapper:
    • Encuentra el HWND de la ventana Hwgui con FindWindowA
    • Crea el WebView2 como ventana independiente
    • Quita los estilos de ventana de nivel superior, lo convierte en WS_CHILD
    • Llama a SetParent para incrustarlo dentro de la ventana Hwgui
    • Instala una subclass en WM_SIZE de la ventana Hwgui
  4. Cuando el usuario redimensiona/maximiza, la subclass captura WM_SIZE y llama a webview_set_size, redimensionando el Chromium interno
  5. Harbour llama a navigate_webview para cargar la URL
  6. Al cerrar, Harbour llama a destroy_webview, que elimina la subclass y destruye el WebView

10. Solución de problemas

ErrorCausaSolución
hb_LibLoad devuelve NILFaltan dependencias en tiempo de ejecuciónVerifica con objdump -p webview_wrapper.dll | grep "DLL Name" — si aparece libc++.dll, recompila con -static
webview_create devuelve NULLWebView2 Runtime no instaladoInstala el Evergreen Runtime (paso 2.6)
webview_get_window devuelve NULLwebview_create no completóVerifica el runtime
El WebView queda en blancoError de renderizadoVerifica si el WebView2 Runtime está actualizado
El WebView no se redimensionaLa subclass no se está llamandoVerifica que create_webview_embedded se ejecutó sin errores
hb_DynCall devuelve NILLa función no está exportadaVerifica con objdump -p webview_wrapper.dll | grep export
Error == en punteroComparar un puntero con un número en HarbourUsa solo hWebView != NIL, nunca hWebView == 1
