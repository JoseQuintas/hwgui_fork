2. Pré-requisitos

2.1 Instalar o MSYS2

O MSYS2 é o ambiente que fornece o Clang 22, o linker LLD e as bibliotecas necessárias no Windows sem depender do Visual Studio.

Download: https://www.msys2.org/

Instalação:

  1. Baixar o instalador msys2-x86_64-*.exe
  2. Executar e instalar no caminho padrão: C:\msys64
  3. Na tela final, marcar a opção "Run MSYS2 now" e finalizar
  4. Após a instalação, você terá vários atalhos no menu Iniciar:
    • MSYS2 UCRT64 — não usar
    • MSYS2 MINGW64 — não usar
    • MSYS2 CLANG64 — usar este
    • MSYS2 MSYS — não usar
Importante: todos os comandos deste manual devem ser executados dentro do MSYS2 CLANG64, não no CMD, não no PowerShell, não no MSYS2 padrão.

2.2 Atualizar o MSYS2 (primeira vez)

Na primeira vez que abrir o MSYS2 CLANG64, atualize a base de pacotes:

pacman -Syu

Se ele pedir para fechar o terminal e reabrir, faça isso e rode de novo:

pacman -Syu

Repita até ele não pedir mais para reiniciar.

2.3 Confirmar que está no ambiente CLANG64

Antes de instalar qualquer coisa, confirme que está no ambiente correto:

echo $MINGW_PACKAGE_PREFIX

Deve aparecer exatamente:

mingw-w64-clang-x86_64

Se aparecer qualquer outra coisa (mingw-w64-ucrt-x86_64, mingw-w64-x86_64, ou vazio), você abriu o terminal errado. Feche e abra o MSYS2 CLANG64.

2.4 Instalar os pacotes necessários

Instale o toolchain completo, o SDK do WebView2 e o Git:

pacman -S --needed \
  mingw-w64-clang-x86_64-toolchain \
  mingw-w64-clang-x86_64-webview2-loader \
  git

Durante a instalação, o pacman vai pedir confirmação várias vezes. Aperte Enter para aceitar o padrão (que é "sim").

O que cada pacote traz:

PacoteFornece
mingw-w64-clang-x86_64-toolchainClang 22, Clang++, LLD, libc++, libunwind, headers do Windows, make, etc.
mingw-w64-clang-x86_64-webview2-loaderWebView2.h, WebView2EnvironmentOptions.h e WebView2Loader.dll
gitCliente Git (para baixar o repositório da webview)

2.5 Verificar a instalação

Confirme que tudo está no lugar:

clang --version

Deve mostrar algo como:

clang version 22.1.8 (...)
Target: x86_64-w64-windows-gnu
InstalledDir: C:/msys64/clang64/bin
clang++ --version

Deve mostrar a mesma versão do Clang, com target x86_64-w64-windows-gnu.

ls /clang64/include/WebView2.h

Deve mostrar o caminho do arquivo (sem erro).

ls /clang64/bin/WebView2Loader.dll

Deve mostrar o caminho do arquivo (sem erro).

git --version

Deve mostrar a versão do Git instalada.

Se todos esses comandos retornaram sem erro, o ambiente está pronto. Pode seguir para a seção 3.

2.6 Instalar o WebView2 Runtime (no Windows, fora do MSYS2)

O WebView2 Runtime é o motor Chromium da Microsoft (por volta de 200 MB) que a sua aplicação vai usar em tempo de execução. É instalado no Windows, uma vez só, e não é algo que fica junto do seu projeto.

Instalação via winget (mais rápido, no CMD):

winget install --id=Microsoft.EdgeWebView2Runtime -e

Instalação manual (alternativa):

  1. Abra: https://developer.microsoft.com/microsoft-edge/webview2/
  2. Procure por "Evergreen Standalone Installer"
  3. Baixe a versão x64
  4. Execute o instalador como administrador

Confirmar que está instalado (no CMD):

reg query "HKLM\SOFTWARE\WOW6432Node\Microsoft\EdgeUpdate\Clients\{F3017226-FE2A-4295-8BDF-00C3A9A7E4C5}" /v pv

Se aparecer algo como pv REG_SZ 1xx.x.xxxx.xx, está instalado. Se der erro "não pôde localizar a chave", não está instalado.

Nota: em máquinas com Windows 10/11 atualizado, o WebView2 Runtime costuma vir pré-instalado junto com o Microsoft Edge. Sempre confirme com o comando acima antes de assumir.

4. Criar o wrapper em C

Criar o arquivo C:\dev\webview\webview_wrapper.c com o conteúdo:

#include <webview/webview.h>
#include <stdint.h>
#include <windows.h>

static webview_t g_webview = NULL;
static WNDPROC   g_old_proc = NULL;
static HWND      g_parent   = NULL;

static LRESULT CALLBACK SubclassProc(HWND hwnd, UINT msg, WPARAM wp, LPARAM lp) {
    if (msg == WM_SIZE && g_webview != NULL) {
        int w = LOWORD(lp);
        int h = HIWORD(lp);
        if (w > 0 && h > 0) {
            webview_set_size(g_webview, w, h, WEBVIEW_HINT_NONE);
        }
    }
    return CallWindowProc(g_old_proc, hwnd, msg, wp, lp);
}

extern "C" {

__declspec(dllexport) void* create_webview_embedded(const char* parent_title, const char* title, int width, int height) {
    HWND hwnd_parent = NULL;
    if (parent_title && parent_title[0]) hwnd_parent = FindWindowA(NULL, parent_title);
    if (!hwnd_parent) hwnd_parent = GetActiveWindow();
    if (!hwnd_parent) hwnd_parent = GetForegroundWindow();
    if (!hwnd_parent) return NULL;

    webview_t w = webview_create(0, NULL);
    if (!w) return NULL;

    webview_set_title(w, title);

    HWND hwnd_wv = (HWND)webview_get_window(w);
    if (!hwnd_wv) { webview_destroy(w); return NULL; }

    LONG_PTR style = GetWindowLongPtr(hwnd_wv, GWL_STYLE);
    style &= ~(WS_POPUP | WS_CAPTION | WS_THICKFRAME | WS_OVERLAPPED |
               WS_SYSMENU | WS_MINIMIZEBOX | WS_MAXIMIZEBOX);
    style |= WS_CHILD;
    SetWindowLongPtr(hwnd_wv, GWL_STYLE, style);

    LONG_PTR exstyle = GetWindowLongPtr(hwnd_wv, GWL_EXSTYLE);
    exstyle &= ~(WS_EX_CLIENTEDGE | WS_EX_WINDOWEDGE |
                 WS_EX_DLGMODALFRAME | WS_EX_STATICEDGE);
    SetWindowLongPtr(hwnd_wv, GWL_EXSTYLE, exstyle);

    SetParent(hwnd_wv, hwnd_parent);

    RECT rc;
    GetClientRect(hwnd_parent, &rc);
    int cw = rc.right > 0 ? rc.right : width;
    int ch = rc.bottom > 0 ? rc.bottom : height;

    webview_set_size(w, cw, ch, WEBVIEW_HINT_NONE);
    SetWindowPos(hwnd_wv, HWND_TOP, 0, 0, cw, ch,
                 SWP_FRAMECHANGED | SWP_NOACTIVATE | SWP_SHOWWINDOW);

    g_webview = w;
    g_parent  = hwnd_parent;
    g_old_proc = (WNDPROC)SetWindowLongPtr(hwnd_parent, GWLP_WNDPROC, (LONG_PTR)SubclassProc);

    return (void*)w;
}

__declspec(dllexport) void navigate_webview(void* w, const char* url) {
    if (!w) return;
    webview_navigate((webview_t)w, url);
}

__declspec(dllexport) void destroy_webview(void* w) {
    if (!w) return;
    if (g_parent && g_old_proc) {
        SetWindowLongPtr(g_parent, GWLP_WNDPROC, (LONG_PTR)g_old_proc);
        g_old_proc = NULL;
        g_parent   = NULL;
    }
    g_webview = NULL;
    webview_destroy((webview_t)w);
}

}

5. Compilar a DLL

No MSYS2 CLANG64:

cd /c/dev/webview

clang++ -shared -O2 -std=c++17 -static -x c++ \
  -o webview_wrapper.dll \
  webview_wrapper.c core/src/webview.cc \
  -Icore/include -DUNICODE -D_UNICODE \
  -luser32 -lole32 -loleaut32 -lshlwapi \
  -ladvapi32 -lversion -lcomctl32 -lntdll -ldwmapi \
  -fuse-ld=lld

Flags explicadas:

FlagSignificado
-sharedGera DLL
-O2Otimização
-std=c++17Padrão C++ da lib webview
-staticLinka libc++/libunwind estaticamente (evita depender das DLLs do MSYS2 em runtime)
-x c++Trata todos os arquivos como C++
-Icore/includeDiretório dos headers da webview
-DUNICODE -D_UNICODEMacros do Win32
-l...Bibliotecas do Windows
-fuse-ld=lldUsa o linker do LLVM

Verificar os exports:

objdump -p webview_wrapper.dll | grep -iE "create_webview|navigate_webview|destroy_webview"

Deve mostrar:

create_webview_embedded
destroy_webview
navigate_webview

Verificar que não depende de DLLs do MSYS2 (não pode ter libc++.dll):

objdump -p webview_wrapper.dll | grep "DLL Name"

Deve listar apenas DLLs do Windows (KERNEL32.dll, USER32.dll, etc).

7. Código Harbour (Hwgui)

Arquivo webview_test.prg:

#include "hwgui.ch"
#include "hbdyn.ch"

STATIC pLib     := NIL
STATIC hWebView := NIL

FUNCTION Main()
   LOCAL oForm

   pLib := hb_LibLoad( "webview_wrapper.dll" )
   IF pLib == NIL
      hwg_MsgStop( "Falhou hb_LibLoad" )
      RETURN NIL
   ENDIF

   INIT WINDOW oForm TITLE "Hwgui + WebView2" SIZE 800, 600 ;
      ON INIT { || InicializaWebView( oForm ) } ;
      ON EXIT { || FinalizaWebView() }

   ACTIVATE WINDOW oForm

   hb_LibFree( pLib )
RETURN NIL

STATIC FUNCTION InicializaWebView( oForm )
   hWebView := hb_DynCall( { "create_webview_embedded", pLib, ;
                             hb_bitOr( HB_DYN_CTYPE_VOID_PTR, HB_DYN_CALLCONV_CDECL ), ;
                             HB_DYN_CTYPE_CHAR_PTR, ;
                             HB_DYN_CTYPE_CHAR_PTR, ;
                             HB_DYN_CTYPE_INT, ;
                             HB_DYN_CTYPE_INT }, ;
                           "Hwgui + WebView2", "WebView2", 760, 540 )
   IF hWebView != NIL
      hb_DynCall( { "navigate_webview", pLib, ;
                    hb_bitOr( HB_DYN_CTYPE_VOID, HB_DYN_CALLCONV_CDECL ), ;
                    HB_DYN_CTYPE_VOID_PTR, ;
                    HB_DYN_CTYPE_CHAR_PTR }, ;
                  hWebView, "https://www.google.com" )
   ENDIF
RETURN NIL

STATIC FUNCTION FinalizaWebView()
   IF hWebView != NIL
      hb_DynCall( { "destroy_webview", pLib, ;
                    hb_bitOr( HB_DYN_CTYPE_VOID, HB_DYN_CALLCONV_CDECL ), ;
                    HB_DYN_CTYPE_VOID_PTR }, ;
                  hWebView )
      hWebView := NIL
   ENDIF
RETURN NIL

Compilar:

hbmk2 webview_test.prg \dev\hwgui\hwgui.hbc -lgdiplus

Rodar:

webview_test.exe

9. Como funciona a integração

  1. Harbour carrega webview_wrapper.dll com hb_LibLoad
  2. Harbour chama create_webview_embedded passando o título da janela Hwgui
  3. A DLL wrapper:
    • Acha o HWND da janela Hwgui via FindWindowA
    • Cria o WebView2 como janela independente
    • Tira os estilos de janela top-level, transforma em WS_CHILD
    • Faz SetParent para dentro da janela Hwgui
    • Instala um subclass em WM_SIZE da janela Hwgui
  4. Quando o usuário redimensiona/maximiza, o subclass captura WM_SIZE e chama webview_set_size, redimensionando o Chromium interno
  5. Harbour chama navigate_webview para carregar a URL
  6. Ao fechar, Harbour chama destroy_webview que remove o subclass e destrói o WebView

10. Solução de problemas

ErroCausaSolução
hb_LibLoad retorna NILFaltam dependências em runtimeVerificar com objdump -p webview_wrapper.dll | grep "DLL Name" — se aparecer libc++.dll, recompilar com -static
webview_create retorna NULLWebView2 Runtime não instaladoInstalar o Evergreen Runtime (passo 2.6)
webview_get_window retorna NULLwebview_create não completouVerificar o runtime
WebView fica brancoErro de renderizaçãoVerificar se o WebView2 Runtime está atualizado
WebView não redimensionaSubclass não está sendo chamadoVerificar se create_webview_embedded rodou sem erro
hb_DynCall retorna NILFunção não está exportadaVerificar com objdump -p webview_wrapper.dll | grep export
Erro == em ponteiroComparação de ponteiro com número no HarbourUsar só hWebView != NIL, nunca hWebView == 1
