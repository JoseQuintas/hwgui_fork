1. Обзор

Что мы собираемся построить:

Hwgui (Harbour)
    │
    └─ hb_LibLoad("webview_wrapper.dll")
         │
         └─ webview_wrapper.dll (скомпилирована с Clang)
              │
              ├─ использует библиотеку "webview" (скомпилирована внутрь)
              │
              └─ загружает во время выполнения: WebView2Loader.dll
                    │
                    └─ использует WebView2 Runtime (установлен в Windows)
КомпонентЧто этоГде находится

2. Требования

2.1 Установка MSYS2

MSYS2 — это окружение, которое предоставляет Clang 22, линкер LLD и необходимые библиотеки в Windows без зависимости от Visual Studio.

Скачать: https://www.msys2.org/

Установка:

  1. Скачайте установщик msys2-x86_64-*.exe
  2. Запустите и установите по умолчанию: C:\msys64
  3. На последнем экране поставьте галочку "Run MSYS2 now" и завершите
  4. После установки в меню «Пуск» появятся несколько ярлыков:
    • MSYS2 UCRT64 — не использовать
    • MSYS2 MINGW64 — не использовать
    • MSYS2 CLANG64 — использовать этот
    • MSYS2 MSYS — не использовать
Важно: все команды этого руководства должны выполняться внутри MSYS2 CLANG64, а не в CMD, не в PowerShell и не в стандартном MSYS2.

2.2 Обновление MSYS2 (первый раз)

При первом открытии MSYS2 CLANG64 обновите базу пакетов:

pacman -Syu

Если он попросит закрыть терминал и снова открыть, сделайте это и снова запустите:

pacman -Syu

Повторяйте, пока он не перестанет просить перезагрузку.

2.3 Проверка окружения CLANG64

Перед установкой убедитесь, что вы в правильном окружении:

echo $MINGW_PACKAGE_PREFIX

Должно быть выведено точно:

mingw-w64-clang-x86_64

Если выводится что-то другое (mingw-w64-ucrt-x86_64, mingw-w64-x86_64 или пусто), вы открыли не тот терминал. Закройте и откройте MSYS2 CLANG64.

2.4 Установка необходимых пакетов

Установите полный тулчейн, SDK WebView2 и Git:

pacman -S --needed \
  mingw-w64-clang-x86_64-toolchain \
  mingw-w64-clang-x86_64-webview2-loader \
  git

Во время установки pacman несколько раз попросит подтверждение. Нажмите Enter, чтобы принять значение по умолчанию («да»).

Что предоставляет каждый пакет:

ПакетПредоставляет
mingw-w64-clang-x86_64-toolchainClang 22, Clang++, LLD, libc++, libunwind, заголовки Windows, make и т.д.
mingw-w64-clang-x86_64-webview2-loaderWebView2.h, WebView2EnvironmentOptions.h и WebView2Loader.dll
gitКлиент Git (для клонирования репозитория webview)

2.5 Проверка установки

Убедитесь, что всё на месте:

clang --version

Должно вывести что-то вроде:

clang version 22.1.8 (...)
Target: x86_64-w64-windows-gnu
InstalledDir: C:/msys64/clang64/bin
clang++ --version

Должно показать ту же версию Clang с target x86_64-w64-windows-gnu.

ls /clang64/include/WebView2.h

Должен вывести путь к файлу (без ошибки).

ls /clang64/bin/WebView2Loader.dll

Должен вывести путь к файлу (без ошибки).

git --version

Должно показать установленную версию Git.

Если все команды отработали без ошибок, окружение готово. Переходите к разделу 3.

2.6 Установка WebView2 Runtime (в Windows, вне MSYS2)

WebView2 Runtime — это движок Chromium от Microsoft (около 200 МБ), который ваше приложение будет использовать во время работы. Он устанавливается в Windows, один раз, и не входит в состав вашего проекта.

Установка через winget (быстрее всего, в CMD):

winget install --id=Microsoft.EdgeWebView2Runtime -e

Ручная установка (альтернатива):

  1. Откройте: https://developer.microsoft.com/microsoft-edge/webview2/
  2. Найдите "Evergreen Standalone Installer"
  3. Скачайте версию x64
  4. Запустите установщик от имени администратора

Проверка установки (в CMD):

reg query "HKLM\SOFTWARE\WOW6432Node\Microsoft\EdgeUpdate\Clients\{F3017226-FE2A-4295-8BDF-00C3A9A7E4C5}" /v pv

Если выводится что-то вроде pv REG_SZ 1xx.x.xxxx.xx, значит установлено. Если появляется ошибка «не удаётся найти указанный раздел или параметр реестра», значит не установлено.

Примечание: на машинах с обновлённой Windows 10/11 WebView2 Runtime обычно уже установлен вместе с Microsoft Edge. Всегда проверяйте командой выше, прежде чем предполагать.

4. Создание C-обёртки

Создайте файл C:\dev\webview\webview_wrapper.c со следующим содержимым:

#include <webview/webview.h>
#include <stdint.h>
#include <windows.h>

static webview_t g_webview = NULL;
static WNDPROC   g_old_proc = NULL;
static HWND      g_parent   = NULL;

static LRESULT CALLBACK SubclassProc(HWND hwnd, UINT msg, WPARAM wp, LPARAM lp) {
    if (msg == WM_SIZE && g_webview != NULL) {
        int w = LOWORD(lp);
        int h = HIWORD(lp);
        if (w > 0 && h > 0) {
            webview_set_size(g_webview, w, h, WEBVIEW_HINT_NONE);
        }
    }
    return CallWindowProc(g_old_proc, hwnd, msg, wp, lp);
}

extern "C" {

__declspec(dllexport) void* create_webview_embedded(const char* parent_title, const char* title, int width, int height) {
    HWND hwnd_parent = NULL;
    if (parent_title && parent_title[0]) hwnd_parent = FindWindowA(NULL, parent_title);
    if (!hwnd_parent) hwnd_parent = GetActiveWindow();
    if (!hwnd_parent) hwnd_parent = GetForegroundWindow();
    if (!hwnd_parent) return NULL;

    webview_t w = webview_create(0, NULL);
    if (!w) return NULL;

    webview_set_title(w, title);

    HWND hwnd_wv = (HWND)webview_get_window(w);
    if (!hwnd_wv) { webview_destroy(w); return NULL; }

    LONG_PTR style = GetWindowLongPtr(hwnd_wv, GWL_STYLE);
    style &= ~(WS_POPUP | WS_CAPTION | WS_THICKFRAME | WS_OVERLAPPED |
               WS_SYSMENU | WS_MINIMIZEBOX | WS_MAXIMIZEBOX);
    style |= WS_CHILD;
    SetWindowLongPtr(hwnd_wv, GWL_STYLE, style);

    LONG_PTR exstyle = GetWindowLongPtr(hwnd_wv, GWL_EXSTYLE);
    exstyle &= ~(WS_EX_CLIENTEDGE | WS_EX_WINDOWEDGE |
                 WS_EX_DLGMODALFRAME | WS_EX_STATICEDGE);
    SetWindowLongPtr(hwnd_wv, GWL_EXSTYLE, exstyle);

    SetParent(hwnd_wv, hwnd_parent);

    RECT rc;
    GetClientRect(hwnd_parent, &rc);
    int cw = rc.right > 0 ? rc.right : width;
    int ch = rc.bottom > 0 ? rc.bottom : height;

    webview_set_size(w, cw, ch, WEBVIEW_HINT_NONE);
    SetWindowPos(hwnd_wv, HWND_TOP, 0, 0, cw, ch,
                 SWP_FRAMECHANGED | SWP_NOACTIVATE | SWP_SHOWWINDOW);

    g_webview = w;
    g_parent  = hwnd_parent;
    g_old_proc = (WNDPROC)SetWindowLongPtr(hwnd_parent, GWLP_WNDPROC, (LONG_PTR)SubclassProc);

    return (void*)w;
}

__declspec(dllexport) void navigate_webview(void* w, const char* url) {
    if (!w) return;
    webview_navigate((webview_t)w, url);
}

__declspec(dllexport) void destroy_webview(void* w) {
    if (!w) return;
    if (g_parent && g_old_proc) {
        SetWindowLongPtr(g_parent, GWLP_WNDPROC, (LONG_PTR)g_old_proc);
        g_old_proc = NULL;
        g_parent   = NULL;
    }
    g_webview = NULL;
    webview_destroy((webview_t)w);
}

}

5. Компиляция DLL

В MSYS2 CLANG64:

cd /c/dev/webview

clang++ -shared -O2 -std=c++17 -static -x c++ \
  -o webview_wrapper.dll \
  webview_wrapper.c core/src/webview.cc \
  -Icore/include -DUNICODE -D_UNICODE \
  -luser32 -lole32 -loleaut32 -lshlwapi \
  -ladvapi32 -lversion -lcomctl32 -lntdll -ldwmapi \
  -fuse-ld=lld

Пояснение флагов:

ФлагЗначение
-sharedСоздать DLL
-O2Оптимизация
-std=c++17Стандарт C++, используемый библиотекой webview
-staticСтатически слинковать libc++/libunwind (избавляет от зависимости от DLL-ок MSYS2 во время выполнения)
-x c++Обрабатывать все файлы как C++
-Icore/includeКаталог заголовков webview
-DUNICODE -D_UNICODEМакросы Win32
-l...Библиотеки Windows
-fuse-ld=lldИспользовать линкер LLVM

Проверьте экспорты:

objdump -p webview_wrapper.dll | grep -iE "create_webview|navigate_webview|destroy_webview"

Должно вывести:

create_webview_embedded
destroy_webview
navigate_webview

Проверьте, что DLL не зависит от библиотек MSYS2 (не должно быть libc++.dll):

objdump -p webview_wrapper.dll | grep "DLL Name"

Должны быть только DLL-ки Windows (KERNEL32.dll, USER32.dll и т.д.).

7. Код Harbour (Hwgui)

Файл webview_test.prg:

#include "hwgui.ch"
#include "hbdyn.ch"

STATIC pLib     := NIL
STATIC hWebView := NIL

FUNCTION Main()
   LOCAL oForm

   pLib := hb_LibLoad( "webview_wrapper.dll" )
   IF pLib == NIL
      hwg_MsgStop( "hb_LibLoad failed" )
      RETURN NIL
   ENDIF

   INIT WINDOW oForm TITLE "Hwgui + WebView2" SIZE 800, 600 ;
      ON INIT { || InicializaWebView( oForm ) } ;
      ON EXIT { || FinalizaWebView() }

   ACTIVATE WINDOW oForm

   hb_LibFree( pLib )
RETURN NIL

STATIC FUNCTION InicializaWebView( oForm )
   hWebView := hb_DynCall( { "create_webview_embedded", pLib, ;
                             hb_bitOr( HB_DYN_CTYPE_VOID_PTR, HB_DYN_CALLCONV_CDECL ), ;
                             HB_DYN_CTYPE_CHAR_PTR, ;
                             HB_DYN_CTYPE_CHAR_PTR, ;
                             HB_DYN_CTYPE_INT, ;
                             HB_DYN_CTYPE_INT }, ;
                           "Hwgui + WebView2", "WebView2", 760, 540 )
   IF hWebView != NIL
      hb_DynCall( { "navigate_webview", pLib, ;
                    hb_bitOr( HB_DYN_CTYPE_VOID, HB_DYN_CALLCONV_CDECL ), ;
                    HB_DYN_CTYPE_VOID_PTR, ;
                    HB_DYN_CTYPE_CHAR_PTR }, ;
                  hWebView, "https://www.google.com" )
   ENDIF
RETURN NIL

STATIC FUNCTION FinalizaWebView()
   IF hWebView != NIL
      hb_DynCall( { "destroy_webview", pLib, ;
                    hb_bitOr( HB_DYN_CTYPE_VOID, HB_DYN_CALLCONV_CDECL ), ;
                    HB_DYN_CTYPE_VOID_PTR }, ;
                  hWebView )
      hWebView := NIL
   ENDIF
RETURN NIL

Компиляция:

hbmk2 webview_test.prg \dev\hwgui\hwgui.hbc -lgdiplus

Запуск:

webview_test.exe

9. Как работает интеграция

  1. Harbour загружает webview_wrapper.dll через hb_LibLoad
  2. Harbour вызывает create_webview_embedded, передавая заголовок окна Hwgui
  3. DLL-обёртка:
    • Находит HWND окна Hwgui через FindWindowA
    • Создаёт WebView2 как отдельное окно
    • Убирает стили окна верхнего уровня, превращает в WS_CHILD
    • Вызывает SetParent, чтобы встроить его внутрь окна Hwgui
    • Устанавливает subclass на WM_SIZE окна Hwgui
  4. Когда пользователь изменяет размер/разворачивает окно, subclass перехватывает WM_SIZE и вызывает webview_set_size, изменяя размер внутреннего Chromium
  5. Harbour вызывает navigate_webview для загрузки URL
  6. При закрытии Harbour вызывает destroy_webview, которая удаляет subclass и уничтожает WebView
